How the simulator is built

OBJECTS IN ORBIT.

The Python engine is the source of truth. Its objects model a closed, imaginary network; the Three.js scene turns each event into a visible packet, impact, and explanation.

  • Inheritance — BotFleet, Router, and Server are specialized Device objects.
  • Polymorphism — every device implements receive(packet) with its own response.
  • Strategy — firewall, rate limiting, DNSSEC, and encryption are interchangeable defense objects.
  • Factory — AttackFactory creates one of four Attack subclasses.
  • Composition — Simulation combines devices, defenses, and the selected attack.
  • WebSocket events — the browser receives compact JSON events from FastAPI and animates them.

Scenarios are deliberately bounded educational illustrations. Port numbers are labels inside the toy simulation; no scan or network operation is performed.
