PROJECT STRUCTURE

How the simulation works

The Python engine models network devices, traffic, attack scenarios, and defenses. The 3D view shows the same simulated events as they move through the topology.

  • Devices — clients, routers, and services each handle traffic according to their role.
  • Attack scenarios — each scenario creates a different kind of synthetic network event.
  • Defense strategies — firewall rules, request limits, DNS checks, and encryption can be enabled independently.
  • Live connection — the browser sends choices to the local Python backend over a WebSocket.

The engine demonstrates abstraction, inheritance, polymorphism, composition, strategy objects, and a factory.
